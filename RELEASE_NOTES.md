**Sendling 1.0.5**

- **Rename files** — right-click a sent file → **Rename…** to rename it on the server. Works across every backend (FTP/FTPS/SFTP/WebDAV/Nextcloud/Dropbox), and the share link updates to match.
- **Clearer share-link feedback** — when a Nextcloud/Dropbox share link can't be created (usually a missing `sharing` permission), Sendling now tells you the actual reason instead of showing a misleading "set a Download URL" message.

Download `Sendling-v1.0.5.dmg`, open it, drag Sendling to Applications. Requires macOS 14 (Sonoma) or later. Universal (Apple silicon + Intel), signed and notarized. Zero dependencies.
